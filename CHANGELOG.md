# Changelog

## 0.1.0

- Erasure (Article 17) and access (Article 15) request templates in English
  and Finnish.
- `gdpr-kit draft` writes one request per service and a tracker CSV from a
  services list and a private identity file.
- `gdpr-kit deadline` and `gdpr-kit due`: calendar-month deadlines with the
  end-of-month and weekend rules, extensions, identity questions, reminders,
  follow-ups and escalation dates.
- Tracker template and a Google Sheets guide with the same formulas.
- Deadline guide in English and Finnish.
- Tests, CI and a privacy scan of the full Git history.
